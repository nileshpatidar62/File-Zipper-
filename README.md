# File Zipper Software – Huffman Compression Algorithm 📦

This project is a **File Zipper Software** developed using the **Huffman Compression Algorithm**, a widely used lossless data compression technique. The application compresses and decompresses text files efficiently by generating variable-length binary codes based on character frequency. It demonstrates strong knowledge of **Data Structures and Algorithms (DSA)**, **file handling**, **binary trees**, and **data compression techniques** while providing an easy-to-use interface for reducing file size without losing any information.

## ⚙️ How It Works

1. Reads the input text file.
2. Calculates the frequency of every character.
3. Builds a **Huffman Tree** using a Min Heap (Priority Queue).
4. Generates unique binary codes for each character.
5. Encodes the original text using Huffman codes.
6. Stores the compressed data along with metadata required for decoding.
7. During decompression, reconstructs the Huffman Tree and restores the original file exactly.
